# Wesh Star IA v4.1 — clean self-hosted patch

- Preserved Admin, Moderator, Autopilot, social retry, generation, storage, database and payment features.
- Fixed Twitch label/status handling in admin and moderator UI.
- Twitch can now be connected with a stream key instead of a nonexistent OAuth start route.
- Twitch Autopilot now uses the server's local FFmpeg process to send generated MP4 output to Twitch RTMPS.
- Added Twitch to the typed Autopilot profile settings so the existing settings UI is consistent.
- Kept Snapchat's manual token flow and all existing official OAuth flows.
- Worker documentation now refers to self-hosted cron/systemd instead of Vercel Cron.
- No Supabase/Stripe/Replicate dependency was added.

## Important
Social-network publication necessarily uses the official network APIs and credentials.
Twitch additionally requires FFmpeg installed on the Wesh Star IA server.


## GPU-local verification patch
- Confirmed video generation is routed only through `gpu-worker/` and not through a hosted video API.
- Kept the existing FFmpeg multi-scene assembly path.
- Updated the optional Wan I2V pipeline to use CPU offload rather than forcing the full model into CUDA VRAM, making the 24 GB-class GPU target more practical.
- No existing UI, quotas, roles, autopilot permissions, native storage, or direct-payment flow were removed.
