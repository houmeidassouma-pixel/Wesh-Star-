# Wesh Star IA — Community Feed V1

## Owner-controlled rollout
- `site.communityEnabled` defaults to `false`.
- When false, the community navigation, publish button and `/community` page are hidden/disabled.
- When the Admin switches it on in Admin > Settings > Contrôles de lancement, the feature becomes available immediately from the database-backed settings.

## User publishing
- Any completed video owned by the user can be published to Wesh Star IA.
- Existing external publishing/download features remain unchanged.
- Visibility options: Public, Followers, Private.
- A video can only be published from its owner's completed generation.

## Community
- Feed tabs: Pour toi, Tendances, Suivis.
- Likes, comments, follows and reports.
- Native local-storage video URLs are signed by Wesh Star IA.

## Moderation
- Admin and moderation staff can hide, remove and restore community posts.
- Reports are visible in the moderation panel.
- Existing user account disable/reactivate controls remain available.
- The Admin can globally disable new user registrations or moderator invitations with blue toggles.
